# Power System Analysis & Protection

A three-phase power system analysis and overcurrent protection model developed using MATLAB Simulink.

## Project Overview

This project demonstrates the analysis of a three-phase power system and the implementation of overcurrent protection using MATLAB Simulink.

The model includes a three-phase source, transformer, measurement blocks, fault implementation, RMS current measurement, and an overcurrent protection mechanism.

## Key Features

- Three-phase power system modeling
- Three-phase voltage and current measurement
- Transformer modeling
- Fault analysis
- RMS current measurement
- Overcurrent detection
- Protection signal generation
- MATLAB Simulink based simulation

## Software Used

- MATLAB R2024b
- Simulink
- Simscape Electrical / Specialized Power Systems

## Project Model

The Simulink model represents a three-phase electrical system with measurement and protection components.

## How to Run

1. Download the `.slx` file from this repository.
2. Open MATLAB/Simulink.
3. Open `Power_System_Analysis_Protection.slx`.
4. Run the simulation.
5. Observe the measured voltage, current, RMS current and protection output.

## Applications

This project provides practical understanding of:

- Power system modeling
- Fault analysis
- Electrical protection
- Overcurrent protection
- Three-phase system measurements
